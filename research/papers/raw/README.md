# Raw papers inbox

**Inbox only.** Drop a PDF, HTML (with `_files/`), or `.txt` here and tell the agent.

## Rule (do this every time)

1. Read the dump.
2. Extract into `research/papers/<nn>-*.md`: problem, method, results (all tables/numbers that matter), limitations, numbers to beat, how we differ.
3. Copy important result/architecture figures to `research/figures/baselines/` (see [`../../ARTIFACTS.md`](../../ARTIFACTS.md)).
4. Update related work / still-needed list / reading log.
5. **Delete this dump** (the file and any `_files/` folder). Do not keep PDFs or HTML mirrors in git.

This folder should contain **only this README** after processing.
